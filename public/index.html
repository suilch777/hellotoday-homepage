WHAT WE DO

매일의 안부를
자연스럽게 확인합니다.

대상자는 익숙한 휴대전화로 안부를 전하고, 보호자는 확인 결과를 앱에서 살펴볼 수 있습니다.

01 / CHECK IN☀

아침과 저녁 안부 확인

정해진 시간에 안부 확인 화면을 열어 일상 속에서 응답할 수 있도록 돕습니다.

02 / FAMILY♡

보호자에게 소식 전달

안부 확인 결과와 시간, 확인 방법을 연결된 보호자가 확인할 수 있습니다.

03 / HELP✳

필요할 때 도움 요청

대상자가 도움을 요청하면 연결된 보호자에게 알림을 보내고 연락을 돕습니다.

안부가 늦어지면 보호자에게 알리고, 대상자에게 다시 확인을 요청하는 기능도 제공합니다.

HOW IT WORKS

서로 다른 화면,
하나의 안심.

대상자와 보호자가 각자의 역할에 맞는 화면을 사용합니다.

01

대상자가 안부를 확인합니다

휴대전화 화면과 음성 안내를 따라 간편하게 응답합니다.

02

보호자가 결과를 살펴봅니다

확인 여부와 시간, 도움이 필요한 상황을 앱에서 확인합니다.

03

필요하면 바로 연락합니다

보호자는 대상자에게 전화하거나 안부 확인을 다시 요청할 수 있습니다.
